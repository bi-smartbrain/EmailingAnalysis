**Модуль `ETL_sent_emails.py`**

**Назначение:**  
ETL процесс отправленных писем из Close в аналитическую БД с выявлением ключевых фраз в теме письма.

**Основные функции:**
1. Загрузка из БД диапазона дат уже сохранённых писем.
2. Создание последовательных интервалов времени (например, по 5 минут) для постепенной обработки новых данных.
3. Получение списка отправленных писем из CRM Close для каждого временного интервала.
4. Автоматическое определение ключевых фраз в темах писем с помощью алгоритма (функция `add_subject_key_into_emails`), который:
   - Использует уже известные фразы из БД.
   - Обнаруживает новые фразы и добавляет их в базу для дальнейшего использования.
5. Сохранение обработанных писем в БД с приведением дат к московскому времени (UTC+3).

**Технические особенности:**
- Обработка данных порциями (по временным диапазонам) для избежания перегрузки источников данных.
- Механизм обработки ошибок: при сбое в диапазоне он запоминается, и процесс продолжается.
- Динамическое обновление справочника ключевых фраз по мере появления новых тем в письмах.

**Используемые технологии:**  
Python, pandas, работа с базами данных, обработка временных рядов, текстовый анализ.

**Результат:**  
База данных `sent_emails` постоянно пополняется новыми отправленными письмами, каждое из которых помечено ключевой фразой из темы для последующей аналитики.
